写博客最常用的 Markdown 语法都在这里了，看到什么语法可以直接对照着用。

## 标题与强调

```markdown
## 二级标题
### 三级标题
**加粗** 与 *斜体*，还有 `行内代码`。
```

效果：**加粗**、*斜体*、`行内代码`。

## 列表

```markdown
- 无序列表项
- 再一项
  - 嵌套项

1. 有序列表
2. 第二项
```

## 代码块

指定语言可以高亮（当前示例页本身就在展示这一点）：

```js
function greet(name) {
  return `你好，${name}！`;
}

console.log(greet('读者'));
```

## 引用

```markdown
> 一句值得引用的话，会以左侧强调条的形式展示。
```

> 一句值得引用的话，会以左侧强调条的形式展示。

## 表格

```markdown
| 语法 | 用途 |
| --- | --- |
| 列表 | 归纳要点 |
| 代码块 | 贴代码与命令 |
| 表格 | 对比信息 |
```

## 链接与分隔线

```markdown
[链接文字](https://example.com)
```

用三个以上的 `---` 可以插入分隔线：

---

以上就是高频语法，写文章时随时可以回来查。祝下笔如有神。
