2026 年 2 月，第二段实习收官，毕业也进入倒计时。趁这个节点，把四年攒下的技能与荣誉完整盘点一遍，既是给简历时间线系列收尾，也是给自己一份阶段性的交代。

## 专业技能

- **开发能力**：熟练使用 Python 的 **FastAPI** 与 **Flask** 框架，具备高性能 RESTful API 的设计与开发经验（交通中台与情感分析服务都是实战）。
- **AI 技术栈**：熟悉 **LangChain** 生态与 **RAG** 架构，具备 Prompt 工程与向量数据库 **FAISS** 的落地经验；了解 Agent 的设计与编排（详见站内 Agent 学习系列）。
- **数据存储与处理**：掌握 **MySQL**、**HBase** 数据库设计，了解 **Redis**、**RabbitMQ** 的基础操作与使用场景。
- **工具与规范**：熟练使用 **Docker** 进行容器化部署，掌握 **Nginx** 反向代理配置。
- **算法与视觉**：会用 PyTorch / PyTorch-Lightning 训练与集成模型，接触过 PaDiM、FastFlow、STFPM 等无监督缺陷检测模型。

## 四年回顾

回头看，这四年的主线很清楚：**课程打底 → 竞赛与项目练手 → 实习见真章 → 系统学习补盲区**。大一大二把计算机基础课啃扎实，大二下开始进竞赛（蓝桥杯、计算机设计大赛），大三把 CV 与 LLM 项目做深（慧眼、情感分析），大四在真实业务里扛住亿级数据（两段实习），毕业前又花半年系统补齐了 Agent 方向的认知。

技术栈会过时，但这套"先搞清楚问题、再选型、再做闭环、最后复盘"的方法不会。下一站，带着这套方法论继续往前。
