欢迎来到我的博客。我是张煜坤，一名数据科学与大数据技术专业的本科生。这个站点将长期记录我的学习与成长：课程里啃下的硬骨头、比赛和项目中的复盘与踩坑、实习一线的工程经验，以及对 AI 前沿技术的持续探索。

## 这个博客写什么

- **学习笔记**：数据结构、数据库、机器学习等课程里值得沉淀的内容——写下来，才是最有效的复习。
- **项目复盘**：从工业缺陷检测到情感分析，每一个完整项目的设计思路、技术选型与结果数据。
- **实习与工程**：真实业务场景下的数据采集、存储、治理与交付经验。
- **AI 专题**：对 Agent、RAG 等新技术的系统学习，会以连载专题的形式呈现（例如我正在更新的 Agent 学习系列）。

博客不追热点，只记录真实的思考与进步。若干年后回头看，希望能清楚看到自己一步步走过的路。

## 如何快速添加一篇新文章

在 `src/content/blog/` 目录下新建一个 Markdown 文件（文件名会成为网址后缀，建议英文小写加连字符），开头写一段 frontmatter 即可：

```yaml
---
title: 文章的标题
description: 一段用于首页摘要与 SEO 的简介。
pubDate: 2026-09-09
tags:
  - 标签一
  - 标签二
draft: false
---
```

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题 |
| `description` | 是 | 摘要，显示在卡片与搜索引擎结果中 |
| `pubDate` | 是 | 发布日期，格式 `年-月-日`，决定文章在时间线上的位置 |
| `tags` | 否 | 标签数组，用于自动归档 |
| `updatedDate` | 否 | 最近更新日期，可选 |
| `draft` | 否 | 设为 `true` 则不会发布 |

写完正文保存即可：首页文章列表、标签页与 RSS 都会自动更新，不需要改任何其他代码。

## 本地预览与发布

```bash
npm install    # 首次安装依赖
npm run dev    # 本地开发，默认 http://localhost:4321
npm run build  # 构建静态产物到 dist/
```

站点已接入 Git 与 Cloudflare Pages：`git commit` + `git push` 后会自动构建并发布到线上，具体流程见《用 Astro 搭建博客并部署到 Cloudflare Pages》。
