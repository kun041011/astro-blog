欢迎来到我的博客。我是张煜坤，即将入读长春理工大学数据科学与大数据技术专业。这个站点会长期记录我的学习与成长：课程里的知识沉淀、动手实践的记录，以及对一个又一个新技术方向的好奇与探索。我会尽量把真实的过程写下来，包括卡住的地方和想通的瞬间。

## 这个博客写什么

- **学习笔记**：课堂内外值得沉淀的知识——写下来，才是最有效的复习。
- **实践记录**：把学到的东西真正用起来的过程，包括课程设计、小工具与踩过的坑。
- **技术观察**：对感兴趣的技术方向保持跟踪，慢慢形成自己的判断。
- **阶段小结**：每隔一段时间回头看一次，记录自己走到了哪一步。

博客不追热点，只记录真实的学习与思考。若干年后回头看，希望能清楚看到自己一步步走过的路。

## 如何快速添加一篇新文章

在 `src/content/blog/` 目录下新建一个 Markdown 文件（文件名会成为网址后缀，建议英文小写加连字符），开头写一段 frontmatter 即可：

```yaml
---
title: 文章的标题
description: 一段用于首页摘要与 SEO 的简介。
pubDate: YYYY-MM-DD
tags:
  - 标签一
  - 标签二
draft: false
---
```

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题 |
| `description` | 是 | 摘要，显示在卡片与搜索引擎结果中 |
| `pubDate` | 是 | 发布日期，格式 `年-月-日`，决定文章在时间线上的位置 |
| `tags` | 否 | 标签数组，用于自动归档 |
| `updatedDate` | 否 | 最近更新日期，可选 |
| `draft` | 否 | 设为 `true` 则不会发布 |

写完正文保存即可：首页文章列表、标签页与 RSS 都会自动更新，不需要改任何其他代码。

## 本地预览与发布

```bash
npm install    # 首次安装依赖
npm run dev    # 本地开发，默认 http://localhost:4321
npm run build  # 构建静态产物到 dist/
```

站点接入了 Git 与 Cloudflare Pages：`git commit` + `git push` 之后会自动构建并发布到线上，不需要手动上传文件。
